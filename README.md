# Harbourview Plumbing Inc Website

A fast, mobile-friendly static landing page for Harbourview Plumbing Inc in Wasaga Beach, Ontario.

## Preview locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
